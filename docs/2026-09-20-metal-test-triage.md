## How retirement was decided

A pure grammar, state, serialization, size or fake-store decision can move to the actual instrument that exercises it. A build, fake flash, structural grep or injected TxDone cannot retire physical flash retention, power loss, real IRQ timing, transport delivery or pixels. “src is not compiled by native” is not a sufficient coverage argument: several probes compile the real firmware command/UI TUs; some config/board paths are extracted or structural only. Those limits are explicit below. No firmware test, simulator run, probe or mutation battery was re-run for this documentation change; these are **source-validated coverage locations**, not a new software-gate receipt.

Each AUTO ID is linked from a single `RETIRED → instrument` row in the new plan's results table. Retirement applies only to the named pure subchecks, never to the entire mixed Part. Native suite invocation remains `pio test -e native` followed by the actual binary; latest software gate evidence and pins live in [BASELINE](../simulation/BASELINE.md), not copied here.
