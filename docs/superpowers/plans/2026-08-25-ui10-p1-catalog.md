## Scope (spec §3-P1, binding)
`PresetCatalog` in a new pure header (K1's `firmware_team_keyring.h` is the template — study its magic/
four-state-read/coalescing/wipe idioms before writing): the `'MRU1'` `/mrui` record — 17 fixed slots
`{enabled, loc, len, text[18]}` + generation, sized and static_asserted; compiled defaults exactly §3.2.2's
table (emergency `I'm in danger` loc=on mandatory · dm1/dm2 + channel1/channel2 enabled · 3..8 disabled).
- **The four-state storage policy, verbatim from the spec:** absent ⇒ defaults, NO warning · invalid/
  unsupported ⇒ defaults + a visible COUNTED warning, a later successful mutation MAY rewrite the complete
  canonical catalog (repair) · io_failed ⇒ defaults + a DISTINCT warning, every mutation returns `store` with
  ZERO writes (⛔ never overwrite a possibly-intact record after a transient read failure) · valid ⇒ loaded.
- **Canonical record bytes, each a pin:** generation starts at 1, SKIPS ZERO on wrap · `enabled`/`loc` exactly
  0/1 · emergency `enabled=1` always · bytes after `len` zero · disabled slots zero length/text/location ·
  padding/reserved NAMED and zero · candidate generation saved WITH the candidate, live state changes only
  after the save succeeds.
- **Validation:** 1..17 printable ASCII (OQ-A ruled — 17 for EVERY preset, both loc states; `text[18]` = 17 +
  terminator), ⛔ `"` `\` CR LF, ≥1 non-space; violations = `bad_text` etc. per §3.2.3's reason set.
- **Coalescing:** byte-identical write ⇒ zero saves (counted) — ⛔ the pin holds ONLY over a valid-or-absent
  store; against `invalid` a repair-write is legitimate even when live values equal defaults.
- Emergency: always-enabled, text-editable, ⛔ never clearable/disableable (`mandatory`). Factory reset erases
  `/mrui`. ⛔ `/mrcfg`/`mrnv::Blob` untouched — a phrase edit can never reprovision the node.
- The `busy` table from spec §2 applies at the SERVICE level where reachable (an active-emergency flag input);
  the modal-close half is P3's — expose the typed verdicts P2/P3 will consume.

## Pins (from spec §4, the P1-reachable set)
Pins 3 (emergency invariants), 7 (four states each behave; `/mrcfg` untouched in all), 8 (coalescing with the
ruled limit), 12 (every canonical-byte rule: wrap skips zero · disabled all-zero · tail-after-len zero ·
candidate-then-live order) — plus the validation boundary both sides of 17. Mutations (each RED at match
count 1): emergency clear accepted · defaults-on-corrupt silently unwarned · io_failed treated as invalid
(the repair-write against a possibly-intact record) · the catalog written through `mrnv::Blob` · generation
wrap lands on zero · coalescing dropped (every set writes) · a canonical-zeroing rule dropped (tail garbage
survives) · candidate/live order inverted (live before save).
