## 0. One spec correction before the brief is written

Spec §12-S1a item 3 ("Strengthen activation uniqueness across all mobiles, explicitly flipping the current B251
case") is a **behaviour change**: today `deleg_ack_activation_available` admits a second ACTIVE row with the same
wire-visible return key when the mobile hash differs (`lib/core/node_hashlocate.cpp:1929`), and the existing test
`test/test_dual_layer.cpp:3915` asserts both rows are admitted. Refusing the second row changes an admission
decision and flips a test. That cannot sit inside a slice whose title is "behavior-neutral" and whose gate is
"36/36 byte-identical" (C1: refactor XOR feature). **Move item 3 to S1b.** Corpus impact of the eventual change is
nil (home counters are per-destination, `lib/core/node_mac.cpp:20-32`, so no natural collision exists), which is
exactly why it must not hide inside the refactor: the refactor's byte-identity gate would not see it either way.

## 3. Everything the refactor touches outside `lib/core`

- **Tests reach into the ring.** `test/test_dual_layer.cpp:404-418` (`DualLayerTestAccess::deleg_ack_put/xlate/
  deleg_ack_live_n`) use `Node::DelegAckPeer`, `Node::DelegAckState` and iterate `n._deleg_acks` directly through the
  friend seam (`node.h:3644`); `node.h:943-946` (`test_deleg_ack_live_n`) does the same. Recommendation: keep the
  public names `DelegAckPeer`, `DelegAckState`, `kDelegAckNoSlot` and the seven `deleg_ack_*` methods (`node.h:2243-
  2260`). A rename storm is not a layout change; if the spec's "names are implementation choices" is exercised, add
  aliases and change nothing else.
- **Mutation harness.** All eight `MUTS_B251HASH` entries (D01-D08) quote ring-internal source text
  (`tools/probe_ui_model_mutations.py:6276-6310`); `X07`, `X10`, `X11` in `MUTS_B251RX` quote the admission site.
  Every one must be re-matched after the refactor (match count exactly 1) and re-proven RED. The four
  `PIN_CASES/PIN_ASSERTS` re-sync applies if S1a adds cases.
- **Mirror probe.** `tools/probe_b278_row_abi.py`'s `MrB278CurrentRowMirror` mirrors the 24-byte row and compiles
  `node.h`'s `static_assert(sizeof(DelegAck) == 24)` in the same TU. After S1a the candidate IS the production row:
  the current-row mirror must be retired or re-pointed, and the `static_assert` it bridges to becomes `== 32`.

## 6. Corpus and reachability facts the brief should state

byte-identity alone and by native tests. The XL park-fire `deleg_ack_put` at `node_hashlocate.cpp:2259` is

it through the renamed authority but cannot drive it; say so rather than claiming coverage.
