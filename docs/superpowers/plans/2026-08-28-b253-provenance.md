## The one-paragraph slice
`tools/git_rev.py`'s ordinary path becomes: resolve the worktree root from PlatformIO's explicit
`$PROJECT_DIR` → validate the short `HEAD` id (ASCII hex) → ONE fail-loud porcelain query
(`git status --porcelain=v1 --untracked-files=normal --ignore-submodules=all`, stdout treated as **bytes**,
empty-vs-non-empty only, ⛔ no filename decode/listing) → `-dirty` iff non-empty → inject + print with
`source=git` (or `source=override` on the validated S2 seam, exact value, no Git invoked). Every Git-failure
arm (no git / not a repo / no commit / empty-malformed revision / status non-zero) ABORTS the board build with
one bounded diagnostic — ⛔ never `nogit`, ⛔ never a traceback as the primary message. Detached HEAD is valid.
The C++ `#ifndef GIT_REV` fallback stays for native/custom, its comment corrected to no longer imply a board
env may use it.
