# B278 S2 — Quality-Agent pre-check ledger (2026-09-02)

Source facts for the S2 (codec extension) brief, verified at the post-S1b working tree with the seventh table
ruling landed. Every `file:line` is current at the time of writing; re-verify before quoting (V2). This ledger is

## 0. What S2 is, in one line

The wire form only: allocate `notice_flags` bit 6 (`0x40`, HOME_TRANSLATED), define the 8-byte translated tail
(`original_reporter u8 · target_kind u8 · mobile_ctr u16 LE · target_value u32 LE`, offsets 24–31, record 32),
one pack/parse authority, golden vectors, docs drafts. **No producer and no consumer of the translated form
exist after S2** (S3 originates, S4 consumes) ⇒ the corpus must be byte-identical on the ruled table and every
receiver must behave exactly as today.

## 2. The four parse callers — S2 must leave every one compiling AND behaving as today

| caller | anchor | behaviour today | S2 obligation |

| USB line in firmware | `src/fw_main.cpp:1679` | same | ⚠ outside `lib/core`; keep the parse signature source-compatible or the fence must name `src/fw_main.cpp` |

⇒ **Recommend an ADDITIVE API**: keep `parse_custody_failure(body)` and `pack_custody_failure(rec, out)`
signatures intact (the parser merely stops refusing bit 6 and exposes `translated()` / the flag on the record),
and add `parse_custody_translated_tail(body, rec) -> optional<CustodyTranslatedTail>` plus
`pack_custody_failure_translated(rec, tail, out)` (32). Spec §6.3's sentence *"`parse_custody_failure` returns
whether the translated flag is set plus the parsed tail"* is satisfied by the flag being visible on the record
plus the tail accessor; changing the return type would touch all four callers including `src/`.

## 3. Validation rules the codec must own (spec §6.3), and which layer owns the rest

Codec (well-formedness): bit 7 refused; bit 6 set ⇒ `record_len >= 32`; `original_reporter` in 1..254;
`target_kind ∈ {0,1}`; `mobile_ctr != 0`; `target_value != 0`; kind `node_id` ⇒ `target_value == failed_dst`;
kind `key_hash` and `HAS_DST_HASH` set ⇒ `target_value == dst_hash32`; bytes beyond 32 retained as a future tail
(`custody_record_tail` must now start at 32 for a translated record — its `custody_record_v1_len` base is wrong
for that case; give it the record's own prefix length). The direct packer keeps refusing `record_len != 24` and
bit 6; the translated packer refuses everything the direct one refuses plus a bad tail.
Receiver terms (`failed_origin == this node`, `reporter_layer`, mobile-only acceptance, `DST_HASH == self`) are
S4's, not the codec's — the same split G drew for the plane value (`frame_codec.cpp:1270-1273`).
