**Rulings I made (each within the brief; cost if wrong):**
1. **The comparator's wording is a parameter**, not only the `[[B456]]` tag. `control`, `ctl` and `controls accounted`
   keep every firmware-UI line byte-identical, and the board-UI passes `probe identity`, `its recorder` and
   `identities accounted`. *Cost:* message text only.
2. **The copy resolves the library through a link the test sets up.** The runner finds it only at
   `$ROOT/tools/probe_accounting.sh`, and the test links `<d>/tools/probe_accounting.sh` to the real file; there is
   no environment override. A missing library exits 2 with its own message. *Cost:* one line in each runner.
3. **`schk` takes an explicit, stable identity first**, and S3's loop words carry `<id>|<pattern>`
   (`draw_frame`, `begin_frame`, `on_page`), because some labels embed measured values (brief §2.2.1). *Cost:* the
   structural identity names, which are frozen in the manifest.
4. **The census's accepted syntax is deliberately narrow and documented in `accounting.py`.** It admits a
   `"$VAR[/literal/path]"` file argument (W52 uses `"$ROOT/platformio.ini"`), and a loop template is either `$var` or
   `${var%%|*}`. Anything else fails closed. *Cost:* a future call shape needs a census edit.
5. **Each layer's outcome decision is one function** (`trait_outcome` …), used by that layer and by the selftest,
   reproducing the old decision order exactly. *Cost:* the diff is larger than a one-line `rec` per exit.
6. **`CHK` is `CHK_AT_`, with `#expr` stringified in the outer macro**, so the FAIL text is the source text exactly as
   before (proven byte-identical). *Cost:* none measured.
7. **negctl removes the record variables from each mutant binary's environment**, a second guard beside the runner's
   `unset`. *Cost:* one `env=` argument.
8. **The early exits end with a verdict line.** A census failure and a positive-build failure print `FAIL` (and, in
   `--no-neg`, the banner) before exiting 1. A failing `--no-neg` run prints `FAIL` and then the banner, so the banner
   is always the last line and PASS never appears. *Cost:* last-line wording on failure paths.
9. **The synthetic mode ends in `PASS`/`FAIL`**, labelled by its header line ("SYNTHETIC accounting selftest …
   nothing is compiled or run"), mirroring B456's selftest. *Cost:* a reader could skim past the header.
10. **The suite's scratch tree copies `src/`, `lib/` and `variants/`**, because W44 walks them with a plain `find`,
    which does not follow a link. The real-run cases assert the **exact** set of failures, so an unrelated failure
    cannot hide behind an expected one. *Cost:* about 6 MB copied per copy case.
11. **The manifest carries a comment header**, with the author line and the limit. `#` lines are skipped by the runner
    and never compared. *Cost:* none.
