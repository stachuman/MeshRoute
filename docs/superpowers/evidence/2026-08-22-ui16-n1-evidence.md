## 1 — What N1 is, in one paragraph, so the measurements below are readable

N1 is the read-only nearby-team observation cache: a Node-global RAM ring (`lib/core/team_seen_ring.h`) written at
**one site** in `lib/core/node_beacon.cpp`, immediately after the existing leaf/team drop, gated on
`b.is_mobile && peer_team != 0`. It writes RAM only — ⛔ no route, peer, membership, key or NV write, no TX, no timer
id, **no `MR_EMIT`**, zero wire bytes. The two `const` accessors have `!MR_FEAT_TEAM` inert stubs, and the two members
are `#if MR_FEAT_TEAM`, so a gateway build holds none of it.

The committed mutation battery lives in `tools/probe_ui_model_mutations.py` under **two targets**:
`--target=teamseen` (7 entries, the pure ring policy) and `--target=teamseensite` (7 entries, the one write site).
Both ran a full pass: **14 RED / 0 unusable**, source md5 restored and MATCHING, exit gate green on both.

## 3 — ★★ THE TWO-ENV BOARD LADDER (D2): PRE / AFTER

**The two envs are the ones QG named, and their identities are verified in `platformio.ini`:**
`gateway` = `env:xiao_sx1262` + `${gateway_flags}` (`-DMR_PROFILE_GATEWAY` ⇒ **`MR_FEAT_TEAM 0`**, nRF52840 / ARM

### 3.1 — Method, including the two things that would otherwise have contaminated it

**A THREE-POINT LADDER, so N1 is isolated and the K1/K2 bytes are NAMED rather than smeared into it.** The working
tree carries the **uncommitted K1/K2 keyring slice** as well as N1, so a plain HEAD-vs-worktree A/B would have
measured both at once. Three trees instead, none of them the real one (⛔ never `checkout`/`stash` in the real tree):

| tree | how it was made | contains |
|---|---|---|
| `head` | `git archive HEAD \| tar -x` | HEAD only — **no K1/K2, no N1** |
| `pre` | copy of the working tree with **N1 reverted** (`git show HEAD:` over the three `lib/core` files; the two new files deleted) | HEAD + **K1/K2** |
| `post` | copy of the working tree, untouched | HEAD + K1/K2 + **N1** |

★ **`pre → post` is therefore N1 ALONE**, and that is sound because **K1/K2 touches no `lib/` file at all** — every
hunk in `git diff -- lib/` is N1's (the include, the accessors, the stubs, the members, the `sizeof(Node)` ledger, the
write site, the two constants), which is exactly what the spec's *"exactly one slice touches `lib/core`"* predicts.

⚠ **`GIT_REV` WAS PINNED TO A FIXED STRING (`"abtest0"`) IN ALL THREE SCRATCH COPIES, AND WITHOUT THAT THE FLASH
COLUMN WOULD HAVE BEEN JUNK.** `tools/git_rev.py` injects `-DGIT_REV` from `git rev-parse`: a tree with no `.git`
yields `"nogit"` (5 chars) while the real tree yields `"83a8e3a-dirty"` (13). That is a per-tree flash offset with no
relation to the code under test. ⛔ The real `tools/git_rev.py` was never modified.

### 3.3 — What each figure establishes

- ★★★ **`gateway` is BYTE-IDENTICAL across N1 — `+0` RAM, `+0` flash, `+0` `g_node`.** This is the feature-off
  evidence the host reveal alone could not give: on a real `MR_FEAT_TEAM 0` image the two members compile out, the
  accessors fold to `return 0` / `return nullptr` and are uncalled, and the observe stub is an empty inline. Stronger
  than the predicted "+0 RAM" — even the flash does not move.
- ★★★ **`heltec_mobile` is `+128 B` RAM, on the nose**, reproducing the host arithmetic
  `sizeof(TeamSeen) 16 x cap_team_seen 8 = 128` **on a different ABI**, which is precisely the axis D2 warns native is
  blind to. It did not move: the board figure and the host figure agree exactly.
- ★★ **`g_node` IS READ OFF THE IMAGE (the ELF symbol table), never inferred** — the standing lesson that a static
  instance's size must come from the image. Raw symbols, for anyone re-checking:
  `gateway 20008f40 00024488 B g_node` (0x24488 = 148616) · `heltec_mobile POST 3fca3fb8 0001cc58 B g_node`
  (0x1cc58 = 117848) · `heltec_mobile PRE 3fca3fb8 0001cbd8 B g_node` (0x1cbd8 = 117720).
- ✅ **QG's two confirmed AFTER figures — `heltec_mobile` `g_node` 117,848 and `gateway` `g_node` 148,616 — are
  reproduced EXACTLY by the coder's independent ELF read above.** ⓘ Recorded as agreement between two separately
  produced measurements, ⛔ not as a QG approval of anything else in this file.
- The `+268 B` flash on the full-team env is the write site plus the inlined ring observe. ⓘ The accessors are still
  **uncalled** — their consumer is slice **N2** — so this figure will grow when N2 lands, and that is expected.
