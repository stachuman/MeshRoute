## 2. The two layouts, and who owns which validation

### 2.1 Direct — 24 bytes, byte-identical to pre-S2

Offsets 0-23 exactly as §9.2. `record_len = 24`, bit 6 **clear**. Golden vector in §4.1.

### 2.2 Translated — 32 bytes

| offset | size | field |
| --- | --- | --- |
| 0-23 | 24 | the **unreinterpreted** v1 prefix, with `record_len = 32` at offset 1 and `notice_flags | 0x40` at offset 2 |
| 24 | 1 | `original_reporter` (1..254) |
| 25 | 1 | `target_kind` — 0 `node_id`, 1 `key_hash` |
| 26 | 2 LE | `mobile_ctr`, nonzero |
| 28 | 4 LE | `target_value`, nonzero and kind-valid |

### 2.3 Validation ownership

| term | owner | site |
| --- | --- | --- |
| version, `forwarded`, exactly-one-stage, bit 7, reason, plane==static, four ids 1..254, nonzero ctr, hash⇔flag, reserved==0 | **codec, shared prefix validator** | `custody_prefix_transmittable()` (frame_codec.cpp) — used by BOTH packers |
| bit 6 refused on a packer's INPUT | **codec, shared prefix validator** | same function; each packer stamps offset 2 itself |
| `record_len == 24` (direct) / `== 24` on input then stamped to 32 (translated) | **each packer**, separately | the one field the two forms disagree about |
| `record_len >= 24 && <= body` , version, flags, reason, plane-defined, ids, ctr, hash⇔flag, reserved | **codec, parser** | `parse_custody_failure()` — unchanged |
| bit 6 ⇒ `record_len >= 32`, `record_len <= body`, reporter 1..254, defined kind, `mobile_ctr != 0`, `target_value != 0`, node-id 1..254 **and** `== failed_dst`, key-hash `== dst_hash32` **iff** `HAS_DST_HASH` | **codec, one tail validator + one tail reader** | `custody_tail_transmittable()` + `custody_read_translated_tail()` |
| a key-hash target with **no** `HAS_DST_HASH` is **valid** | codec (deliberate, §6.2) | same |
| `failed_plane` supported, arrival plane, `failed_origin == self`, `failed_type`, `reporter_layer`, the four count/hop domains | **receiver (G's eighteen)** | `Node::custody_failure_receive` — **unchanged, not duplicated** |
| a translated record is REFUSED | **receiver, S2 interim guard** | `Node::custody_failure_receive`, one line, before all of the above |

⛔ **There is exactly one prefix writer (`custody_write_prefix`), one prefix validator, one tail validator and
one tail reader.** `parse_custody_translated_tail` is a two-line forwarder to the same reader
`parse_custody_failure` uses, so "the record parsed" and "the tail reads" cannot disagree.

0xA1B2C3D4 → `D4 C3 B2 A1`, **and** the node-id vector's small value lands at byte 28 with 29-31 zero.
