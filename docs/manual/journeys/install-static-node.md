## Journey

1. Identify the board and required firmware role.
2. Flash the node and verify first boot.
3. Establish a supported management connection.
4. Decide whether this node creates a network or joins an existing one.
5. Apply the verified network configuration.
6. Verify identity, radio settings, and network state.
7. Test communication before final placement.
