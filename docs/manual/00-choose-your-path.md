# Choose Your Path

> Status: Skeleton. Role relationships and journey prerequisites still require source and metal-evidence review.

You do not need to learn every MeshRoute feature before getting started. Choose the journey closest to what you want to accomplish.

## Three questions

1. Will the device travel with a person, or remain installed in one place?
2. Are you using an existing network, or preparing new network coverage?
3. Are you setting up one device, or coordinating a group that needs shared team setup?

## Pick the closest goal

| Starting point | Desired outcome | Guided journey |
| --- | --- | --- |
| You have a mobile device and access to an existing network | Connect, verify operation, and exchange a test message | [Mobile on an Existing Network](journeys/mobile-on-existing-network.md) |
| You are responsible for a fixed node | Create new coverage or add the node to an existing static network | [Install a Static Node](journeys/install-static-node.md) |
| You need to organize people into a team | Establish membership and verify team communication | [Create or Join a Team](journeys/create-or-join-team.md) |
| You are preparing several people and devices for a trip | Configure, test, and operate the group using one checklist | [Prepare a Hiking Group](journeys/hiking-group.md) |

## Paths can overlap

A single setup may use more than one journey. For example, a group organizer may need to prepare mobile devices, establish a team, and install supporting network equipment. Each journey links to the same canonical task chapters so that commands and expected results are maintained in one place.
